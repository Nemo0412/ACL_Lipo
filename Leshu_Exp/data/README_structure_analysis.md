## 🔍 结构-性质关系分析

### 头部结构影响
- **酯基**: 提供适度的脂溶性和代谢位点
- **酰胺键**: 增加氢键受体数，影响水溶性
- **组合效应**: 平衡脂溶性和水溶性

### 尾部结构影响
- **C6-C8**: 适中长度，膜渗透性好
- **C10-C12**: 较长，脂溶性增加，代谢变慢
- **C14-C16**: 过长，严重影响水溶性和代谢
- **双尾结构**: 进一步增加脂溶性和分子量

### 分数趋势
- **7.0-7.5分**: 短链（C6），平衡性较好
- **6.0分**: 中等长度链（C7-C8），开始出现问题
- **5.5分**: 长链或双长链（≥C10），多项性质不佳

## 🚀 使用方法

### Python 读取
```python
import json

with open('efficiency_scores_rdkit_with_reasoning.json', 'r', encoding='utf-8') as f:
    data = json.load(f)

# 查看药物的头部和尾部结构分析
for drug in data:
    print(f"药物 {drug['number']} ({drug['efficiency_score']}分)")
    print(f"Reasoning: {drug['reasoning']}")
    print()
```

### 提取结构信息
```python
# 查找包含特定头部结构的药物
```
