# Data

This directory contains datasets and preprocessing utilities.

## Files

| File | Description |
|------|-------------|
| `virtual_library.xlsx` | Virtual LNP lipid library (2500 molecules) with SMILES and structural features |
| `preprocess.py` | Converts the Excel file to JSONL for model input |
| `virtual_library_preprocessed.jsonl` | Generated by `preprocess.py` (not committed) |
| `efficiency_test_data_rdkit.jsonl` | Test set for efficiency evaluation (add here) |
| `toxicity_test_data_rdkit.jsonl` | Test set for toxicity evaluation (add here) |

## Usage

```bash
python data/preprocess.py
```

Produces `data/virtual_library_preprocessed.jsonl` with fields:
- `ID`, `SMILES`
- `amino_acid`, `protection_group`, `linker_length`, `ester_bonds_OCOO`, `tail_count`
- `features_description`, `estimated_total_carbons`
